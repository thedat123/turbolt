### Detailed description (đây là phần Google index để xếp hạng tìm kiếm — nhồi từ khóa tự nhiên, không nhồi nhét lộ liễu)
```
Turbolt is a free, open-source download accelerator and download manager for Chrome, Edge, and Brave — built to make downloading faster without ads, telemetry, or a paid upgrade wall.

⏬ WHY TURBOLT IS FAST
Regular browser downloads use a single connection. Turbolt splits files into multiple parallel connections (multi-threaded / segmented downloading via HTTP Range requests) so you download at closer to your true internet speed — the same core technique used by Internet Download Manager (IDM) and other download accelerators.

🎬 CAPTURE STREAMING VIDEO (HLS / M3U8)
Turbolt automatically detects HLS (.m3u8) and DASH (.mpd) video streams while you browse, lets you pick the quality, and downloads all segments into a single file — perfect for saving public, non-DRM video content you have the right to download.

✅ CORE FEATURES
• True multi-threaded downloads (1–16 parallel connections, configurable)
• Automatic HLS/M3U8 & DASH video stream detection with one-click download
• Pause / Resume / Cancel individual downloads
• Bandwidth limiting so downloads don't hog your connection
• Hover-to-download button on any downloadable link
• Right-click "Download with Turbolt" on any link
• Clean, fast popup with live progress, speed, and ETA
• Dark mode support
• Automatic fallback to your browser's native downloader for servers that don't support multi-threading — nothing ever fails silently

🔒 PRIVACY FIRST
Turbolt collects zero analytics, zero telemetry, and shows zero ads. It doesn't require an account. Everything runs locally in your browser. Because it's fully open source (GPL-3.0), anyone can read the code and verify these claims — see the GitHub repository linked below.

🆓 FREE FOREVER, NO CATCH
Unlike IDM and other commercial download managers, Turbolt has no trial period, no license key, and no premium tier. It's community-maintained and will stay that way under the GPL-3.0 license, which legally prevents anyone from closing the source in a fork.

🚀 WHO IT'S FOR
Anyone downloading large files (installers, archives, ISOs, datasets) who wants a faster, ad-free alternative to IDM, Free Download Manager, or their browser's default single-threaded downloader — and anyone who wants to save public HLS video streams without a separate desktop tool.

📖 OPEN SOURCE
Full source code, issue tracker, and roadmap: https://github.com/thedat123/turbolt
Found a bug or want a feature? Contributions welcome.

Keywords: download manager, download accelerator, multi-threaded download, IDM alternative, free download manager, m3u8 downloader, hls downloader, video downloader, chrome download manager, open source download manager
```
